We're starting a blog! This is where we'll share studio news, behind-the-scenes notes, and things we learn along the way.

<!--more-->

## What to expect

- **Project stories**: how we approached a brief, what worked, what didn't
- **Process notes**: tools, workflows and small tricks
- **Studio news**: launches, collaborations and events

> Good design is as little design as possible.
> — Dieter Rams

## Writing posts

Every post is a plain Markdown file in `content/blog/`. Create one with:

```bash
hugo new content blog/my-new-post.md
```

Then set `draft = false` when it's ready to publish.

### A table, for good measure

| Format   | Where it goes          |
|----------|------------------------|
| Posts    | `content/blog/*.md`    |
| Images   | `static/img/blog/`     |
| Logo     | `assets/kayte.png`     |
