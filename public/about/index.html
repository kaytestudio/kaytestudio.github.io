About

Kayte Studio is an independent, open-source software studio. We build developer tools from the ground up: a programming language, the IDE to write it in, the compilers that turn it into native code, and even an operating system to run it on.

What we believe

  • Own the whole stack. Building the language, the tools and the platform ourselves lets each layer fit the others and teaches us how everything really works.
  • Write once, run anywhere. From macOS and Linux to Windows, iOS, WebAssembly, ARM boards and microcontrollers, we want the same code to reach as many places as possible.
  • Keep it simple. The BASIC-style syntax, visual RAD form designers and readable code exist to make building software approachable again.
  • Work in the open. Everything we make is on GitHub. You can read the code, file issues, fork it and help shape it.

What we build

The Kayte platform

  • Kayte Lang: a cross-platform language with BASIC-style and JavaScript-like syntaxes. It compiles to bytecode for the Kayte VM, or to native code through C or LLVM.
  • Kayte Studio / KayteIDE: a Qt 6 IDE for Kayte, C++, Pascal/Delphi and Visual Basic, with a drag-and-drop RAD designer and built-in Git and Subversion.
  • KCC, the Kayte C Compiler: a modular C and Objective-C compiler written from scratch in C, built to explore the whole compilation pipeline.
  • Kayte for VS Code: language support for writing Kayte in Visual Studio Code.

Systems and platforms

  • OS/2 Emulation (os24arm): a bare-metal, OS/2 Warp–style operating system for ARM64 and RISC-V, running on QEMU, Raspberry Pi and BeagleBoard hardware.
  • Tilde Desktop: a lightweight, minimalist desktop environment for Unix, macOS and Linux.
  • Valkyrie Engine: a performance-focused C++17 3D game engine for the web and native platforms.

Tooling

  • Qt 6 cross-compilation installer: a toolkit for building Qt 6 apps on macOS that also run on Windows ARM64.

  • Report bugs or suggest features through each project’s issue tracker
