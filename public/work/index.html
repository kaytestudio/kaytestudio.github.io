OS/2 Emulation

An OS/2 Warp–style operating system for ARM64 and RISC-V

A bare-metal, OS/2-style operating system in C11 and AArch64 assembly. It runs on QEMU, Raspberry Pi 3+ and BeagleBoard hardware, with an LX .EXE loader, a DOS-style shell, ext4/btrfs and a GUI compositor.

  • C11
  • AArch64 assembly
  • LLVM / Clang
  • QEMU
