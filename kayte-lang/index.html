Kayte Lang

A Modern, Cross-Platform Programming Language

Kayte Lang is a modern experimental programming language designed for building applications quickly, efficiently, and cross-platform. It compiles into bytecode that runs on the Kayte Virtual Machine (KVM), ensuring portability across macOS, Linux, and Windows.

Get StartedView on GitHub

Quick Start

# Clone the repository
git clone https://github.com/ringsce/kayte-lang.git
cd kayte-lang

# Compile a Kayte program
kaytecc hello.kayte -o hello.kbyte

# Run the bytecode
kayte hello.kbyte

# Or compile to native ARM64 (macOS)
kaytecc hello.kayte --native -o hello
./hello

Core Language Features

Functions

Fully Implemented

Function definition and calls with support for parameters and return values.

Variables & Data Types

Fully Implemented

Variable declaration, assignment, and multiple data types.

Conditionals

Fully Implemented

Efficient branching with if / else if / else, compiled to optimized jump instructions.

Loops

Fully Implemented

for, foreach, and while loops for robust iteration.

Error Handling

Fully Implemented

A try-catch mechanism with exception handler stack management.

Built-in Functions

Fully Implemented

Optimized built-ins compiled directly into single bytecode instructions.

Generics (Type-Erased)

Implemented (parse-time only)

The VM is dynamically typed with no static type-checking pass, so <T, U, ...> lists on structs, classes, functions, and type names are parsed and erased rather than specialized.

STRUCT Pair<A, B>
    First AS A
    Second AS B
END STRUCT

FUNCTION Identity<T>(x)
    RETURN x
END FUNCTION

DIM p AS Pair<Integer, String>

Process Execution

Fully Implemented

The PROCESS statement spawns an OS process, passing arguments directly (no shell interpretation) and optionally capturing output.

PROCESS "whoami" TO currentUser
PRINT currentUser

Beyond the Language

Declarative UI Framework

Build cross-platform UIs with a declarative window/component syntax, backed by separate .kfm form files.

.kfm Form Compiler

Compiles a .kfm form definition straight into a shared/static library (.so / .a / .dylib / .dll) with a small C-callable introspection API - usable from any language with a C FFI.

Bytecode VM

The Kayte Virtual Machine provides fast, portable bytecode execution across all platforms.

ARM64 Native Compilation

Compile directly to native ARM64 executables (macOS, Linux, Windows) for maximum performance.

musl libc Builds

Statically-linked, portable Linux binaries (ARM64 & AMD64) with no runtime dependencies.

HTTP Server & Node.js Integration

A built-in HTTP server for web APIs, plus interop with the npm ecosystem via Node.js.

JVM Interoperability (JNI)

Run Kayte bytecode on the JVM and call bidirectionally between Kayte and Java.

Completed (v0.9)

  • Bytecode VM with file I/O
  • Declarative UI framework (.kfm files)
  • JVM Interoperability (JNI)

Planned (v1.1+)

  • Async/Await: modern asynchronous programming
  • Statically-Checked Generics: type-checked specialization building on type-erased generics
  • Module System: better code organization
  • FFI: call C/C++ libraries directly

Security Advisories

Known security issues in Kayte Lang and its bundled components, and the fix status for each.

SA

Directory traversal in the built-in HTTP server

High

KAYTE-SA-2026:01 · 2026-07-08

SimpleHTTPServer (the HTTP server backing the HTTP SERVER statement, and its components/http demo) concatenated the raw request URI directly into a file path with no containment check. A request such as "GET /../../../../etc/passwd" could read any file readable by the server process.

Affected: 0.9.0 and earlier

Fixed: main branch (2026-07-08) — requests are now resolved against the served directory and rejected if they would escape it.
