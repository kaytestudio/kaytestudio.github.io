void draw_desktop_icons ( void )
static

Draw desktop icons.

Desktop chrome (background, icons, cursor) is compositor-owned, not a client surface, so it draws straight into the shared output framebuffer via fb_* - unlike window content, which is client-owned and only ever touches its own surface buffer via wl_buf_*.

◆ draw_framebuffer_content()

void draw_framebuffer_content ( wl_surface_t * surface,
fb_rect_t damage )

Render live framebuffer test-pattern content into a surface.

Client-side rendering: draws into the surface's own buffer via wl_buf_* (local coordinates, 0,0 = this surface's own top-left corner) - an RGB gradient, primary-color stripes, and the live resolution - to demonstrate a window backed by real pixel content the compositor then blits onto the output, rather than a flat background fill.
