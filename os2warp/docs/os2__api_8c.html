◆ KernThunkStackTo64()

VOID KernThunkStackTo64 ( VOID )

This will convert a 16:32 SS:ESP value to a native 64-bit AArch64 SP value.

There is no such conversion in real OS/2 (32-bit only); this exists purely so 32-bit-shaped callers on this ARM64 port have a way to land back on the native flat 64-bit stack.
