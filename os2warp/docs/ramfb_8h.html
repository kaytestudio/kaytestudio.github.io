Detailed Description

QEMU "ramfb" boot framebuffer configuration (fw_cfg DMA).

ramfb is QEMU's simplest display device: point it at a plain RGB buffer already sitting in guest RAM (via the "etc/ramfb" fw_cfg file, written over the fw_cfg DMA interface) and QEMU continuously displays that memory region directly - no virtqueues, no GPU command submission, no ongoing driver traffic after the one-time setup. Requires the VM to be started with "-device ramfb" (see the run-gui CMake target).
