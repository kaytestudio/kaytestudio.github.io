Detailed Description

On-box "AI" assistant command.

Not a real LLM - there is no network stack in this kernel to reach one. This is a small heuristic assistant that watches which built-in commands get typed at the shell during the current session and uses that to surface usage stats and suggest commands the user hasn't tried yet. State lives in RAM only: the ext4/btrfs drivers in this build are read-only (see fs/ext4/ext4.c, fs/btrfs/btrfs.c), so there's nowhere durable to persist it across reboots yet.
