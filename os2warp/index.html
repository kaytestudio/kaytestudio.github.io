OS/2 Warp 4.52 for ARM64

QEMU virt (Cortex-A72) and Raspberry Pi 3/3+

No libc, no MMU-backed process isolation - kernel, CMD.EXE, and every filesystem driver run in one flat address space. A PL011 UART driver, a DOS-style shell with DOSKEY history/macros, a QuickBASIC-compatible interpreter, a read/write ext4 + btrfs stack behind a small VFS/IFS layer, an OS/2 LX .EXE loader, a Wayland-style GUI compositor with four workplaces, a DEBUG.COM-style memory monitor, and a small on-box heuristic assistant (no network stack, so it just watches what you type).

Boots on QEMU virt (serial console + GUI) | Boots on Raspberry Pi 3+ (less exercised) | Active development

Highlights

DOS Shell + DOSKEY

A DOS-style command shell (DIR/TYPE/COPY/COMP/FC/DEL/REN/MD/RD/CD/VOL/ATTRIB/ECHO/CLS/...). DOSKEY adds Up/Down history, F7/F8/F9 recall, and $-macros with positional args, matching real DOSKEY behavior until it is loaded.

QuickBASIC Interpreter

IF/SELECT CASE, FOR/WHILE/DO LOOP, GOSUB/RETURN, ON...GOTO/GOSUB, DATA/READ/RESTORE, 1-D arrays, and the usual string/math functions - launched with the BASIC command.

ext4 + btrfs, read/write

Real per-group bitmap writes for ext4 (extent trees, dir-entry splitting) and copy-on-write btrfs writes (node/leaf splitting, CRC32C, generation bumping), both cross-checked against real tooling. A standalone f2fs driver exists but is not yet boot-wired.

OS/2 LX Loader + CMD.EXE

RUN <file.EXE> loads and executes real OS/2 LX binaries in the kernel’s own address space - including a standalone CMD.EXE built from the exact same command set as the in-kernel shell.

Wayland-style GUI

A small compositor with four switchable workplaces (Cmd+Escape to cycle), backed by virtio-gpu/ramfb and virtio-input, separate from the serial console.

DEBUG + on-box AI

A DEBUG.COM-style memory monitor (D/E/F/C/M/S, real AArch64 register state) plus a RAM-only heuristic assistant (AI STATUS/STATS/TIP) - a command-usage watcher, not a real LLM.

Platform Support

QEMU virt (development)

  • CPU: Cortex-A72
  • RAM: configurable (2GB in the run/run-gui targets)
  • UART: PL011 @ 0x09000000
  • Load address: 0x40000000
  • Output: os2warp.img
  • Disk: preloaded RAM window (no real VirtIO block driver yet)

Raspberry Pi 3+ (hardware)

  • CPU: Cortex-A53 (64-bit)
  • RAM: 1GB
  • UART: PL011 @ 0x3F201000
  • Load address: 0x80000
  • Output: kernel8.img
  • Disk: none yet

Build & Run (QEMU)

git clone https://github.com/ringsce/os24arm.git
cd os24arm

cmake -B build
cmake --build build --target os2warp.img

# Boot with just the kernel (serial console only)
cmake --build build --target run

# Boot with a real display (Wayland-style compositor, GUI at the prompt)
cmake --build build --target run-gui

# Build + boot with a test ext4 disk (CMD.EXE, HELLO.EXE, README.TXT)
cmake --build build --target run-testdisk

QuickBASIC Interpreter

Type BASIC at the shell to launch it; BYE, QUIT, or SYSTEM returns to the shell.

10 PRINT "Hello from OS/2 BASIC!"
20 FOR I = 1 TO 10
30   PRINT I * I
40 NEXT I
50 END
RUN
